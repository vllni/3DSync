  • Configure folders to sync

    Presets

    Custom Paths

    Path — absolute path on the 3DS SD card to sync, POSIX style. Examples: /3ds/MyApp, /roms/nds

    Name — destination folder on the remote. Use / to create nested folders. Examples: Saves, roms/nds, 3DS/Checkpoint

    Subdirs — when checked, all subdirectories are synced recursively and their structure is preserved on the remote (e.g. /saves/Game/001.sav becomes Name/saves/Game/001.sav). Uncheck to sync only the files directly inside the specified folder, ignoring subdirectories entirely.

    Both ways — full bidirectional sync. The 3DS compares each file against a local manifest (/3ds/3DSync/manifest.json) and against the remote copy, then uploads, downloads, or prompts for conflict resolution as needed.
    Upload only — one-way: the 3DS copy is uploaded and nothing is ever downloaded. Useful for backups. A remote with the Source role is left out: 3DSync never writes to it.

    If Name is left empty the files go directly into the top of the remote (the Drive Folder ID, the SMB folder, the FTP base directory, the WebDAV URL).
